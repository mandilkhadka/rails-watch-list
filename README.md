# Rails Watchlist

A simple web application built with Ruby on Rails for tracking and managing your personal watchlist of movies, TV shows, or any content you want to keep an eye on.

## Features

- User authentication (sign up, log in, log out)
- Add items (movies, shows, etc.) to your watchlist
- Mark items as watched/unwatched
- Categories, genres, or tags for organization
- Optional: Ratings, notes, or reviews for each item
- Search and filter your watchlist
- Responsive design for desktop and mobile

## Getting Started

### Prerequisites

- Ruby (version x.x.x)
- Rails (version x.x.x)
- PostgreSQL or SQLite (default: SQLite)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/mandilkhadka/rails-watchlist.git
   cd rails-watchlist
   ```

2. Install dependencies:

   ```bash
   bundle install
   ```

3. Set up the database:

   ```bash
   rails db:create
   rails db:migrate
   ```

4. (Optional) Seed the database:

   ```bash
   rails db:seed
   ```

5. Start the Rails server:

   ```bash
   rails server
   ```

6. Open your browser and visit: [http://localhost:3000](http://localhost:3000)

## Usage

1. Create an account or log in.
2. Add items to your watchlist by using the "Add" form.
3. Mark items as watched when you finish them.
4. Organize items with categories or tags.
5. Search or filter your watchlist as needed.
